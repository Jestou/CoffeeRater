# Coffee Shop Rater

A web application to rate coffee shops in your area.

## Features

- Add coffee shops with their locations.
- Rate shops (1-5 stars) and provide a username.
- View average ratings for each shop.
- Interactive map to see shop locations.
- Sortable list (Alphabetical or by Rating).

## How to Run

### 1. Install Dependencies
Before running the app for the first time, you need to install the required packages:
```bash
npm install
```

### 2. Start the Development Server
To start the web server in development mode, run:
```bash
npm run dev
```

### 3. Access the Application
Once the server is running, you can access the app by navigating to the following URL in your web browser:
[http://localhost:5173/](http://localhost:5173/)

### 4. Build for Production (Optional)
To create a production-ready build, use:
```bash
npm run build
```
The output will be in the `dist/` directory.

## Technologies Used

- React
- Vite
- Leaflet & React-Leaflet (for maps)
- Lucide React (for icons)
